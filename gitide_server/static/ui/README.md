# Act IA software engineer UI Components

Reusable native UI components for the Act IA software engineer frontend.

## Components

- `select.js` — custom select/dropdown behavior for regular selects.
- `workspace-switcher.js` — workspace/project switcher connected to `#project-selector`.
- `theme-toggle.js` — dark/light theme toggle.
- `checkbox.js` — reserved for checkbox behavior if needed.
- `git-branch-switcher.js` — experimental branch switcher component.

All component styles and shared Design System variables live in `../rebrand.css`.
