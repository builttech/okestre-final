Dispositivos locais

Conectar dispositivos

Escolha o computador e as pastas que deseja compartilhar. Os arquivos continuam na sua máquina. O Connect encaminha as operações autorizadas entre o GPT e o Okestre Local.

ETAPA 1 DE 3

Escolha seu computador

Selecione um dispositivo já pareado ou conecte um novo.

Adicionar outro computador
  1. Informe um nome e gere o código abaixo.
  2. No Windows, abra Okestre Local → Parear.
  3. Informe o endereço do Connect e o código. Depois volte aqui e atualize a conexão.

Sem expiração, o acesso permanece válido até você revogar o computador.

ETAPA 2 DE 3

Adicione seus projetos

Cada pasta é um projeto.

No aplicativo Windows, use Adicionar pasta para compartilhar as pastas dos projetos, por exemplo sendget e meu-site. Depois clique em Atualizar pastas aqui.

Selecione abaixo todos os projetos que deseja adicionar de uma vez. Não é necessário cadastrar arquivos.

ETAPA 3 DE 3

Autorize os projetos no GPT

Os projetos abaixo estão cadastrados no Okestre. Para o GPT acessá-los, autorize-os na conexão do plugin.

  1. No GPT, adicione um servidor MCP com a URL acima e autenticação OAuth.
  2. Entre com a mesma conta usada para parear o computador e selecione os projetos.
  3. Peça ao GPT: “Liste os projetos disponíveis no Okestre Local.”

Se o plugin já estiver conectado, renove a autorização para incluir os novos projetos, caso a conexão não permita todos os projetos futuros.

Mantenha o Okestre Local aberto e o computador conectado. O conteúdo solicitado passa pelo Connect até o GPT.
