Configurando o GPT Action (ChatGPT)

Para conectar o ChatGPT com seu computador usando esta ferramenta de forma segura, siga estes passos:

  1. Exponha seu servidor local:

    Abra um terminal no seu computador e execute um utilitário de túnel como ngrok ou Cloudflare Tunnel (cloudflared):

    # Usando Ngrok
ngrok http 8000

# Ou usando Cloudflare (Grátis sem conta)
cloudflared tunnel --url http://localhost:8000
  2. Obtenha a URL Pública:

    Copie a URL segura gerada pelo túnel (ex: https://abcdef.ngrok-free.app ou https://random.trycloudflare.com).

  3. Crie uma Custom GPT:

    No ChatGPT, vá em Explore GPTs > Create > Configure. Adicione uma Action.

  4. Cole a Especificação OpenAPI:

    Copie o conteúdo de /openapi.json do seu servidor GitIDE (você pode baixar clicando no botão abaixo) e cole no editor de schema da Action. Altere o campo servers para a URL do seu túnel público.
