Configurando o GPT Action (ChatGPT)

Para conectar o ChatGPT com seu computador usando esta ferramenta de forma segura, siga estes passos:

  1. Exponha seu servidor local:

    Abra um terminal no seu computador e execute um utilitário de túnel como ngrok ou Cloudflare Tunnel (cloudflared):

    # Usando Ngrok
ngrok http 8000

# Ou usando Cloudflare (Grátis sem conta)
cloudflared tunnel --url http://localhost:8000
  2. Obtenha a URL Pública:

    Copie a URL segura gerada pelo túnel (ex: https://abcdef.ngrok-free.app ou https://random.trycloudflare.com).

  3. Crie uma Custom GPT:

    No ChatGPT, vá em Explore GPTs > Create > Configure. Adicione uma Action.

  4. Cole a Especificação OpenAPI:

    Copie o conteúdo de /openapi.json do seu servidor Act IA (você pode baixar clicando no botão abaixo) e cole no editor de schema da Action. Altere o campo servers para a URL do seu túnel público.

    Visualizar OpenAPI JSON
  5. Configure a Autenticação:

    Nas configurações de autenticação da Action do ChatGPT, escolha API Key, tipo Bearer e insira o Token do Act IA abaixo:

  6. Configure as Instruções do GPT (GPT Instructions):

    Copie as instruções abaixo e cole no campo Instructions do seu Custom GPT no ChatGPT para guiar a IA de forma segura:

    Você é um Agente de Engenharia de Software conectado ao computador local do usuário via Act IA.
Antes de realizar qualquer tarefa de leitura, escrita ou execução de comandos, você DEVE verificar se existe o arquivo 'GPT_INSTRUCTIONS.md' na raiz do workspace do projeto atual (usando o endpoint de leitura de arquivos).
Se o arquivo existir, leia e siga rigorosamente todas as diretrizes, fases de análise e o protocolo de execução contidos nele.
REGRA INQUEBRÁVEL: antes de executar qualquer task, valide REQ, DRI e Task List. Depois atualize o plano detalhado em .documents/task/task.details.md, aguarde a autorização explícita do usuário no formato "Aprovado executar TASK-REQ-0000-000" e só depois implemente. O plano detalhado não deve ficar somente no chat. Nunca sobrescreva task.details.md apagando seções anteriores; anexe nova seção ou atualize somente a seção da task atual.
